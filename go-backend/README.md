# ANI-RSS Go backend

The Go service is the final public HTTP entry point. It serves the existing Vue
UI and all public API routes without a Java runtime.

From the repository root, build the UI and run the service with:

```sh
pnpm --dir ani-rss-ui install --frozen-lockfile
pnpm --dir ani-rss-ui build
go run ./go-backend/cmd/ani-rss --ui-dir ani-rss-ui/dist
```

Run the repeatable service smoke tests with:

```sh
go test ./go-backend/...
```

The default values are:

- public address: `:7789`
- UI directory: `ani-rss-ui/dist`

Override them with `LISTEN_ADDR`, `UI_DIR`, `CONFIG`, `GO_DOMAINS`, or the
corresponding flags. `MCP_ENABLED` and `SWAGGER_ENABLED` enable their existing
external endpoints. Application data is stored in `ani-rss.sqlite`; legacy JSON
files are imported once at first startup.

Release bundles are generated by `./package.sh`. The script produces Linux,
Windows and macOS Go binaries and copies the unchanged UI beside each binary.
`VERSION` is the release source of truth; `ANI_RSS_VERSION` may override it in
CI. Docker builds the same binary and UI without a Java runtime. The default
release includes server binaries for Linux amd64/arm64/armv7, Windows amd64,
and macOS amd64/arm64; native CI runners package desktop wrappers where used.
